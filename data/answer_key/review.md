# Эталон: черновик для проверки командой

Черновик подготовлен ИИ и **требует проверки людьми**. Решение команды важнее любого пункта.
Данные: `draft.json` (ответ, номер реплики-доказательства, обоснование, уверенность по каждому критерию).

## Как проверять (≈ 40 минут)
1. Каждый берёт свои 7 диалогов (распределение — в плане команды).
2. Открываете диалог в `data/raw/dev.json`, сверяете с таблицей ниже и обоснованиями в `draft.json`.
3. Несогласие → правите `draft.json` и пишете строку в «Журнал правок» внизу.
4. Спорные вопросы из раздела «Решить вместе» обсуждаем всей командой (10 минут).
